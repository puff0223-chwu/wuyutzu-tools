# 🧰 技術招式庫

> 開發手冊的「字典」：用到才查。開工必讀的是 [`HANDBOOK.md`](../HANDBOOK.md)（小抄）。
> 2026-11-12 從第二版完整手冊拆出，內容沒有刪減。

| 需求 | 招式 | 用過的系統 |
|---|---|---|
| 每位學生題目不同、老師又能重算答案 | **固定亂數**：同一組「代碼＋班級＋座號」永遠產生同一組題目，不用存題目 | pH、單位換算、消失的實驗數據 |
| 開始／停止的課堂活動 | 6 碼活動代碼＋`meta.open`，規則檢查 open 才能寫 | No.223、公告欄、遺落的地點 |
| 背景蒐集問卷 | Google 表單無聲送出（fetch POST no-cors），只寫不讀 | DISC、貝爾賓、打掃徵才 |
| 老師分享系統 | 會員中心 `WuStaff.check()`＋規則 `{{STAFF:app}}`；外部系統由伺服器讀會員中心 | 線上檢定所、座位、秘文、課堂小鎮 |
| 好幾個系統任意組合 | 職員證：每個系統只看自己的證；帳本一律寫、讀別人才看證 | 課堂小鎮 |
| 系統之間交換成績 | 📒 成果帳本（source、ref、metric、sid 唯一）＋🔗 帶入欄（用 ref 對欄、改名跟著改公式） | 謎案課堂、英勇學院、線上檢定所 → 成績調閱室 |
| 只能做一次 | 規則 `!data.exists()`；資料庫唯一鍵＋upsert | 改隊名、領獎、評分 |
| 兩人搶同一件事 | 規則只允許狀態從 A→B 一次，慢的被拒顯示「慢了一步」 | 公告欄 |
| 多人同時改同一筆 | `rev` 版本號＋條件更新；衝突重讀重算；一次寫完用資料庫函式 | 英勇學院 `vc_commit`、謎案課堂日誌 |
| 公開排行榜 | 另開只放名字＋成績的抽屜，規則限制欄位 | 器材排行榜 |
| 長時間連線省額度 | 背景 60 秒讓位、回來重連 | `FB.idle()`、`MPC.idle()` |
| 同裝置續答、換裝置不行 | localStorage 存草稿（key 含身分）；Firebase 的裝置鎖＋老師「解除裝置鎖」 | 閱讀測驗、線上檢定所 |
| 斷線不掉資料 | 先存本機佇列（localStorage／IndexedDB），送成功才移除；比對時間決定用本機或雲端 | 遺落的地點、時光手稿、偵探所 |
| 重送不重複 | 學生端編號 `cid`、按讚帶 `want`、upsert、刪除找不到當成功 | 情報板 |
| 單一裁判／主持機 | `host.id`＋心跳；另一台寫入＝接手 | 遺落的地點 |
| 大量即時事件 | 排隊後整批在記憶體判完、一次 update | 遺落的地點（31 秒 → 1 秒） |
| 即時更新又省流量 | 廣播「有變動」→ 自己重抓；定時補抓；共用讀取＋變動時間保證新鮮 | 謎案課堂、情報板 |
| 投影畫面任何螢幕都完整 | 1600×900 固定畫布 `transform: scale(...)` | 謎案課堂 |
| 所有裝置計時一致 | 開頁時向伺服器校時（取來回最快一次） | 謎案課堂 |
| 不用排程的到期／每日恢復 | 誰打開頁面就順手處理到期的、補上經過的恢復次數 | 英勇學院 |
| 圖片 | 瀏覽器端壓縮（最長邊 800～1600px、JPEG／WebP），雜湊或亂數檔名；可 Ctrl＋V 貼上 | 線上檢定所、偵探所、遺落的地點、情報板 |
| GPT 插畫裁切 | rembg 去背（isnet-anime）＋watershed 從軀幹分開黏在一起的角色、腳底對齊、WebP | 英勇學院造型、小鎮插畫 |
| 螢幕常亮 | Wake Lock＋自動再要＋隱形影片後備＋「🔆 常亮」標示 | 公告欄、課堂遊戲化、謎案課堂 |
| 音效 | Web Audio 現場合成，不用音檔 | 課堂遊戲化、英勇學院 |
| 讀秒自動消失的小卡 | CSS 動畫寬度條＋`animation-play-state: paused`（滑鼠停住）＋`onAnimationEnd` | 英勇學院 |
| Excel | 讀用 SheetJS、寫有格式用 ExcelJS；按下才載入 | 消失的實驗數據、各老師頁 |
| Excel 公式 ⇄ 系統公式 | 讀檔加 `cellFormula:true` 拿公式；同列格子→`{欄位}`、固定格→數字；匯出寫 `{t,v,f}` 讓公式活著；匯入前逐格驗算 | 成績調閱室 |
| 名單貼上自動判斷 | 每列判斷分隔（Tab→逗號→2 個以上空白→空白）；沒標題時看內容猜欄位，預覽可改 | 班級名單庫 |
| 說明小圖示 | 純 CSS `.tip::after{content:attr(data-tip)}`；在彈窗表格裡用 portal＋fixed | 線上檢定所、遺落的地點、課堂小鎮 |
| Word 考卷匯入 | mammoth（`styleMap: ['u => u']` 保留底線），題號要在段落開頭 | 線上檢定所 |
| 規則縮寫 | `rules.src.json`＋`build_rules.py`＋targaryen 測試＋GitHub Action 部署 | 全站 |
| 本機模擬 Postgres | PGlite（WASM）跑 schema、RLS、GRANT；假 supabase-js 測伺服器 API | 課堂小鎮 |
| 對外分享頁 | 同一支函式產生說明頁與靜態分享頁（mode 決定有沒有連結），產生時自動檢查零連結；og 預覽圖用 Playwright 排版截圖 | 教師展覽館 |
| 老師自己管理的公開頁 | 內容存 Firebase（公開讀、管理員寫）＋管理頁；靜態檔交給 GitHub Action 看 `rev` 有變才重做；管理頁直接讀首頁 `TOOLS` | 教師展覽館 |
| 頁面跟著另一頁同步 | 存「上次確認過的快照」逐欄比對；身分欄位可自動跟、內容欄位只提醒 | 教師展覽館 ↔ 首頁 |
| 寄信提醒管理員 | 網頁帶 ID token 叫伺服器 → 確認是新的 → Resend；寄成功才記、每天排程補寄 | 會員中心申請通知 |
| 使用量盤點 | 有兩邊鑰匙的伺服器盤點、寫進 `stats`；看不到的數字留 null | 會員中心使用狀況 |
| 舊 Flash／AIR App 復刻 | APK＝zip，內容在 `assets/*.swf`；JPEXS 從原始碼編譯後反編譯 AS3、抽題庫與圖片；先給學生用可 Ruffle 直接播放（AIR 存檔改 SharedObject） | 化學尋寶（`tools/treasure-extract/`） |
| 自動截圖 | 攝影棚：本機假 Firebase＋把正式網址導到本機＋假 `fb.js`＋CDN 改本機套件（`tools/studio/`）；Supabase 系統用模擬模式 | 教師展覽館、小鎮首頁 |
| 試題分析 | 答對率、高低分組 27%、鑑別度 D（純函式 `ExamCore.analyze`） | 線上檢定所 |
| 圖文選單／社群圖 | HTML 排版 → Playwright 指定尺寸截圖 → PIL 壓成 JPG（控制檔案大小） | LINE 圖文選單、og 預覽圖 |
