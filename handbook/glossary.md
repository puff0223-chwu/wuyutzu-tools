# 📖 名詞白話對照與手冊改版紀錄

> 開發手冊的「字典」之一。開工必讀的是 [`HANDBOOK.md`](../HANDBOOK.md)。

## 名詞白話對照

| 名詞 | 白話 |
|---|---|
| 前端／學生頁／老師頁 | 大家在瀏覽器看到、按的畫面 |
| 後端／伺服器（Vercel API） | 店面後面的廚房：藏金鑰、幫學生寫資料、檢查能不能做 |
| 資料庫（Firebase、Supabase） | 倉庫；Firebase 像小型便利倉（快、即時、適合小工具），Supabase 像大型物流倉（能做複雜查詢、長期紀錄） |
| GitHub | 食譜保險箱：每一版程式都留下來，可以回到以前的版本 |
| 部署 | 把新食譜送到店面，網站更新 |
| 規則（Firebase rules）／RLS | 倉庫門口的警衛：誰能拿哪一格 |
| 職員證 | 會員中心開通的系統權限 |
| 成果帳本 | 各系統把算好的成績寫進去的聯絡簿，成績調閱室從這裡拿 |
| 帶入欄（🔗） | 成績表上從別的系統自動帶過來、不能手改的欄 |
| 版本號（rev）／樂觀鎖 | 每次修改都蓋一個號碼章，號碼對不上就知道有人先改過 |
| 冪等 | 同一個按鈕按兩次，結果跟按一次一樣 |
| 保活（cron-job.org） | 定時去倉庫敲門，免得倉庫以為沒人用而關門 |
| 快取／`?v=` 版本號 | 瀏覽器偷懶用舊檔；換版本號＝告訴它「這是新的」 |
| 攝影棚 | 用假資料、假名字自動拍說明頁截圖的測試環境 |
| 模擬模式（mock） | 不連真正資料庫的練習場，測試用 |
